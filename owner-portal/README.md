# Owner Portal 2027 — μηνιαία κατάσταση ιδιοκτήτη (PDF + email)

**Μόνο διαβάζει** από Master Properties, Master File (Bookings), Candy (Έξοδα, Λογαριασμοί), Owner Ledger (Κινήσεις ιδιοκτητών).

Ροή κάθε μήνα: **2. Προεπισκόπηση** (PDF στο 05 Owner Portal/ΕΕΕΕ-ΜΜ/Πρόχειρα, tab «Προεπισκόπηση») → έλεγχος → **✅ Εγκρίθηκε** στο tab «Μήνες» → **3. Αποστολή**.
- Config `PORTAL_MODE = live` → στους ιδιοκτήτες (Owner_Email, + cc από tab «Ιδιοκτήτες») και αρχείο PDF στο 05 Owner Portal/ΕΕΕΕ-ΜΜ. Αλλιώς **ΔΟΚΙΜΗ**: όλα στο TEST_EMAIL ή στον χρήστη.
- Γλώσσα ανά ιδιοκτήτη (EN/ΕΛ) και «Αποστολή ΝΑΙ/ΟΧΙ» στο tab «Ιδιοκτήτες».
- Μήνας = κρατήσεις με check-out μέσα στον μήνα. Εταιρεία: ποσά χωρίς ΦΠΑ · Φυσικό: τελικά ποσά χωρίς αναφορά ΦΠΑ.
- Περιεχόμενο: Σύνοψη (μήνας + από αρχή έτους) · Κρατήσεις · Έξοδα για λογαριασμό σας · Εκκαθάριση (ανοιχτά στοιχεία από το Owner Ledger τη μέρα δημιουργίας).

Στήσιμο: νέο Sheet «Owner Portal 2027» στο 05 Owner Portal · OwnerPortal.gs + appsscript.json · μενού Somnio Portal → 1. Στήσιμο → «Ενεργοποίηση καταγραφής έγκρισης».
