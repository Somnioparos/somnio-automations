# Archive 2026

Τα Apps Scripts της σεζόν 2026, όπως έτρεχαν στα Sheets του προσωπικού λογαριασμού.
**Μόνο για αναφορά** — δεν ανεβαίνουν σε κανένα αρχείο του 2027. Ό,τι χρειάζεται μεταφέρεται
στους φακέλους του 2027 με τις αλλαγές του οδηγού (Config, headers, SomnioCore).

| Αρχείο | Τι έκανε το 2026 |
|---|---|
| Master_File.gs | Sync κρατήσεων Hosthub → Master File, προμήθειες, push στο Owner Invoicing |
| Financials_File.gs | v3.2 — P&L, Occupancy, Στόχοι, Διαθεσιμότητα από Master + Candy |
| Owner_Invoicing.gs | Owner Invoicing tab, email drafts, Elorus περιγραφή |
| Owner_Statements.gs | v2.7 — αρχεία εξόδων/εκκαθάρισης ανά ιδιοκτήτη |
| Schedule_File.gs | Scheduling (σταθερές θέσεις στηλών — να ξαναγραφτεί με headers) |
| Pricing_Plans.gs | Summary / Occupancy 2026 για τα pricing plans |
| Hosthub_Sync.gs | Παλαιότερη έκδοση sync (πριν το Master_File.gs) |
| Import_Owner_Details.gs, Archive_OneOff_Tools.gs, Reconcile*.gs, Z_Patch_DC_Taxes.gs | One-off εργαλεία |
