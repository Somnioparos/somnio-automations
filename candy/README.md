# Candy Recipes 2027

**Αρχείο:** `Candy Recipes 2027` · ID `1eAlBjwenHgrNIIB5AJRN808IIM0rzL9z4EQhRTqv7XE` · Shared Drive / 01 Data
**Config:** `FILE_CANDY` = το παραπάνω ID. Κώδικας: `Candy.gs` + `appsscript.json` (βιβλιοθήκη SomnioCore). Κανένα κλειδί API.

Όλες οι **χειροκίνητες** καταχωρήσεις χρημάτων. Τις διαβάζουν το Financials 2027 (P&L, Cash flow) και το Owner Ledger.

## Tabs καταχώρησης
| Tab | Τι γράφεις | Τι συμπληρώνεται μόνο του |
|---|---|---|
| **Έξοδα** | Ημ/νία, Προμηθευτής, Αρ. παραστατικού, Περιγραφή, Κέντρο κόστους, Λογαριασμός, ΦΠΑ %, **Σύνολο** (ή Καθαρό), Declared, Απόδειξη (link) | ID, Κατηγορία/Υποκατηγορία (από τον προμηθευτή), Φύση, Πλήρωσε, Καθαρό/ΦΠΑ, Ημ/νία πληρωμής (= ημ/νία, αλλάζει), Χρεώνεται σε (ακίνητο ιδιοκτήτη → Ιδιοκτήτης, αλλιώς Somnio· αλλάζει), Οφειλή σε (αν πλήρωσε προσωπικός λογαριασμός) |
| **Κινήσεις** | Κάθε είσπραξη / πληρωμή / μεταφορά που δεν είναι έξοδο: πληρωμές ιδιοκτητών, payouts πλατφορμών, επιστροφές σε συνεταίρους, εγγυήσεις, δάνεια | ID |
| **Concierge** | Υπηρεσίες σε επισκέπτες: ποσό + % προμήθειας | ID, Προμήθεια |
| **Πρόβλεψη** | Μελλοντικές εισροές/εκροές για το Cash flow (π.χ. ενοίκια, δόσεις) | — |

Χρώματα: κίτρινο = γράφεις · ανοιχτό κίτρινο = συμπληρώνεται αν είναι κενό, μπορείς να το αλλάξεις · γκρι = μόνο σύστημα. Προμηθευτής που δεν υπάρχει στη λίστα → **έντονο κίτρινο** + γραμμή στο Έλεγχος.

## Λίστες (γκρι tabs)
- **Προμηθευτές** — από την εγκεκριμένη λίστα 7/11 (79 + 26 «να οριστεί» χωρίς κατηγορία). Νέος = μία γραμμή.
- **Κατηγορίες** — Κατηγορία · Υποκατηγορία · Φύση (Opex / Πάγιο / Εγγύηση / Φόροι) · Στο P&L. **Μόνο το Opex μπαίνει στο P&L**· Πάγια, Εγγυήσεις, Φόροι & τέλη μόνο στο Cash flow.
- **Λογαριασμοί** — Τύπος (Εταιρικός / Προσωπικός / Μετρητά / Πλατφόρμα / Ιδιοκτήτης), Κάτοχος, **Υπόλοιπο 1/1/2027** (για το Cash flow).
- **Άτομα** — Τάσος, Αλέξ, Μίνα, Ελίζα (συνέταιροι), Ευγενία. Νέο άτομο = μία γραμμή· όποιος φεύγει → Active κενό.
- **Ακίνητα** — αντίγραφο από Master Properties 2027 (μην το αλλάζεις εδώ).
- Κέντρα κόστους = Γενικά + Άτομα (ενεργά) + Ακίνητα. Όλα τα κόστη ενός ατόμου (και μισθοδοσία) στο κέντρο του.

## Έλεγχος
Ελλείψεις ανά γραμμή, νέοι προμηθευτές, προσωπικοί λογαριασμοί χωρίς κάτοχο, και **Οφειλές σε συνεταίρους** = πληρωμές από προσωπικούς λογαριασμούς − επιστροφές (Κινήσεις: Πληρώσαμε → Συνέταιρος → όνομα).
